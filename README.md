# Selfie Coach

A real-time selfie coaching web app — all AI runs on-device in the browser; no photos ever leave your phone.

**Live app:** enable GitHub Pages (Settings → Pages → deploy from branch `main`) and open the published URL.

## Roadmap
1. ✅ Step 1 — live camera + face tracking foundation (head pose, expression, lighting, FPS)
2. Step 2 — scoring engine + one-hint-at-a-time live coach
3. Step 3 — burst capture around the score peak, automatic best-shot pick
4. Step 4 — discovery mode: find your best angles, build a personal angle profile
5. Step 5 — AI coach: opt-in cloud vision analysis of your discovery photos
6. Step 6 — generative preview, context modes, PWA polish

Built with MediaPipe Face Landmarker (on-device), vanilla JS, single-file HTML.
